# Customer Churn Prediction

## Project Overview
Customer Churn Prediction is a Machine Learning project that predicts whether a customer is likely to leave a service. It helps businesses identify customers at risk and take steps to improve customer retention.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Machine Learning
- Streamlit

## Project Files
- `app.py` – Application code
- `requirements.txt` – Required Python libraries
- `churn_model.pkl` – Trained machine learning model
- `churn_preprocessor.pkl` – Data preprocessing pipeline
- `churn_threshold.pkl` – Saved prediction threshold

## How to Run the Project

1. Clone or download this repository.
2. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:

   ```bash
   streamlit run app.py
   ```

## Objective
To predict customer churn using machine learning and support data-driven customer retention decisions.
